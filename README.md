# FinanceLab

FinanceLab est une application dédiée à l’apprentissage, au suivi et à l’expérimentation autour de la finance personnelle et de l’investissement. Le projet vise à fournir des outils simples pour analyser, comprendre et simuler des décisions financières.

## 🎯 Objectif

Aider les utilisateurs à mieux comprendre leurs finances, explorer des stratégies d’investissement et suivre leurs évolutions dans le temps.

## ✨ Fonctionnalités

- Suivi de portefeuille (actions, ETF, etc.)
- Visualisation de performance
- Simulations d’investissement
- Suivi d’objectifs financiers
- Interface claire et pédagogique

## 🛠 Technologies

- Swift  
- SwiftUI  
- Architecture MVVM  
- API financières (selon configuration)  
- Stockage local / cloud (à préciser)
